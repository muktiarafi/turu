NEW IN v0.4.0-beta

What's new in Turu

Steadier when you run several accounts, and lighter on slower computers and phones.

Every account in its own lane

Each tab now runs on its own. If one crashes, the others keep farming, and the crashed one restarts by itself.

Smoother on older PCs and phones

Performance mode draws the game a little smaller so it runs faster, and a memory limit keeps long runs light. Find both in Options.

Tips when the game lags

On laptops and phones without a gaming graphics card, if the game keeps lagging, Turu suggests a setting that helps and can switch it on for you.

Better on Android

Each tab gets its own notification with Start, Pause and Stop, and the game's own touch controls are on from the start.
